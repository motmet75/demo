OCR settings

The server administrator configures OCR in secrets/application-secrets.properties and restarts the backend. Credential files stay on the server.

invoice-desk.ocr=google
invoice-desk.google-credentials=C:/secure/google-vision-service-account.json

Use an absolute path on the server, such as /etc/anhmedia/google-vision.json on Linux. This is a Google service-account JSON file, separate from the HTTPS certificate. Google Vision sends document images to Google Cloud.

For local OCR:

invoice-desk.ocr=tesseract
invoice-desk.tesseract-path=C:/Program Files/Tesseract-OCR/tesseract.exe
invoice-desk.tesseract-languages=vie+eng

Install the selected Tesseract language packs. After configuring OCR, select an existing draft and choose Re-run OCR. Review the extracted text and fields before approving.
